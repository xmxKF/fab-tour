# fab-tour

Browser 3D factory-tour game, built with the [fab24hr engine](https://github.com/mcltyl/fab24hr-engine) 0.2.0.

Play: https://xmxkf.github.io/fab-tour/

This is a private, non-commercial learning/demo project. All equipment, companies, people, and numbers are fictional. The upstream fab24hr engine license and credit line are retained in the build and in the ending screen.

- 13 mainline chapters
- 8 process areas (4 mainline + 4 side chapters)
- Traditional Chinese, Simplified Chinese, English, Japanese
